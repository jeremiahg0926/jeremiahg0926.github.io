# Project: Personal portfolio site

Static portfolio site hosted on GitHub Pages from the `main` branch.

## Tech constraints
- Plain HTML, CSS, and JavaScript only. No frameworks, npm, package.json, or build tools.
- Structure: `index.html`, `css/style.css`, `js/main.js`. Ask before adding other files or folders.
- No external scripts, fonts, or CDNs unless I approve them.

## Conventions
- Semantic HTML (header, nav, main, section, footer); accessible markup.
- Mobile-first CSS. All content must work with JavaScript disabled.
- No inline scripts or inline event handlers. External links use rel="noopener noreferrer".

## Workflow rules
- Only change files the task asks for. Keep changes small and reviewable.
- Do NOT run git add, commit, push, reset, or any history-changing command. I handle Git.
- When done, summarize what changed and list anything you could not verify.

## Content rules
- Never invent experience, certifications, projects, or metrics. Use clearly marked placeholders like [TODO: ...].
- Never include employer names, internal tools, configurations, or findings from my job.
